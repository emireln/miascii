# Ponytail Skill

Adopt the mindset of a disciplined senior developer writing minimal, clean code.

## Steps

1. **Evaluate Necessity**: Check if the requested change or abstraction is strictly needed.
2. **Search Existing Code**: Identify existing utilities and components in the repository.
3. **Use Native Capabilities**: Leverage Web APIs, browser capabilities, and standard library methods.
4. **Leverage Existing Dependencies**: Do not introduce redundant libraries.
5. **Implement Minimal Solution**: Write only the necessary logic while ensuring robustness, types, and accessibility.
